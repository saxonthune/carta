# Concept Glossary

The core ideas Rhidoc is built on. Each term carries a one-line purpose (why it exists),
not a restatement of its name. The Facts section ties the terms together as directional
facts; structure is carried there, so a definition need not duplicate it.

## Concepts

### Signals & Context

Signal is flux, and denotes our philosophical commitment to
becoming over being. Signals are encoded into information using symbols. Intention is the underlying meaning behind . Context is
information stored as a collection of symbols.

- **Signal** is flux; rhidoc has a philosophical commitment to becoming as ontologically prior to being (Bergson; Simondon — process metaphysics).
- **Information** is ossified signal, encoded as a collection of symbols (Shannon).
- A **symbol** is the atomic unit of encoded information (Peirce).
- **Context** is the same as information, used when working with an LLM.
- A **Doc** is a unit of information, e.g., a markdown file.
- A **Fact** is a relation between an arbitrary (n-ary) set of entities (Peirce, logic of relatives; ORM fact type).
- **Transduction** is the conversion of signal from one form of information to another (Simondon).
- **Interpretation** is a signal conversion where the source lacks sufficient information, requiring additional information from an implicit source (e.g., an LLM's own information saved inside it).
- An **agent** or (**AI agent**) is an LLM with some degree of neurosymbolic capability.
- An **actor** is a human or agent.

## Facts

Directional facts and splits that tie the defined terms together. Facts touching the
Software Design terms are deferred until those are priced.

- An **actor** *encodes* a **signal** into **information** using **symbols**.
- **Transduction** vs **interpretation** — both convert a **signal**, split by whether the
  source carries sufficient **information**: sufficient → transduction; insufficient →
  interpretation, where an implicit source (e.g., an **AI agent**'s own weights) supplies
  the remainder.
- The **information** in a **doc** *becomes* **context** when read by an **AI agent**.
